Import daily dump

Upload today's tracking dump (CSV, header row required): Tracking ID, Marketplace Order ID, Return ID, Seller name, RTV Shipment ID, TMS Provider name, RTV Shipment Status, RTV Created At, RTV tracking id, Value, Order set ID. A Tracking ID already in the database gets all its fields updated to the new values; a new Tracking ID is added. Only Tracking ID, Value and Qty (scanned at 1 per item) show up on the printed invoice — everything else is kept for reference.

Scan to pack

Pick the brand this box is going to, then scan or type each tracking ID and press Enter — its value is looked up automatically and the item is added straight to the box. Close the box once it's packed, then finish the shipment(s) to print labels & invoices.
